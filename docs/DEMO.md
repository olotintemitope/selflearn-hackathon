# Demo script
1. Show a real handwritten note and a PDF, with permission to use both.
2. Upload and show processing status, extracted text and source pages.
3. Build an ordered concept path.
4. Ask the tutor a question and open its cited source.
5. Answer a three-question quiz, including an intentional wrong answer.
6. Show observed evidence and the recommended weak prerequisite.
7. Read the remedial explanation and answer a follow-up.
8. Disconnect and open a downloaded study pack; reconnect and sync a queued attempt once.
9. Show a second-domain fixture to establish domain independence.

Label any seeded results or prerecorded fallbacks. Do not present simulated integrations as live. Explain progress as a POC heuristic with limited evidence.

## Recording configuration
Run on localhost with private local file storage. Keep DevTools Network visible for slow-network navigation, Offline reload and quiz queueing, then reconnect and verify exactly-once sync. Follow docs/LOW_BANDWIDTH.md and keep credential screens out of the recording.
