# Slice 3: Quiz → evidence → recommended revision

**Backlog status:** Core past-paper flows are built, with candidate-level qualitative feedback available for submitted written and fill-gap answers. Learners can connect a ready answer key to one exact paper and verify objective answers individually against both original pages. Real scanned-paper verification, scoreable written marking, paper-set feedback, and mixed-paper live acceptance remain. The feedback slice has fake-provider tests only; it has not been verified with a live provider, real paper, or live browser. See [the prioritized backlog](../BACKLOG.md).

## Verification
Test deterministic behavior and failures with provider fakes; exercise the visible flow and record evidence. Feature tests travel beyond each server deadline, submit otherwise-correct answers, and verify that no late answer is scored and the result is finalized as unanswered. Expired past-paper sessions also finalize when reopened. The candidate-level written-feedback slice is covered by synthetic success and ambiguous-source fixtures, strict-schema/citation tests, owner-only result tests, and failure fallback tests. This slice has no live provider, real scanned-paper, or browser acceptance evidence.

## Current limitation
The imported bank supports self-study practice using current clear questions from one or more uploaded papers. The learner can choose a 30, 60, or 90 minute practice timer. Mixed sets accept papers from one owned study space and preserve each question's source paper, year hint, and page. Paper years are upload-label hints. Detected marks are not summed or used for scoring. Owner-checked candidates can be corrected and practised, but remain ungraded until an answer is checked against a linked key. Untouched clear objective answer labels may still be scored as an unverified comparison. A learner-confirmed answer-key-to-paper association alone does not establish any individual answer. For objective questions, the owner can now compare both original pages, select an answer, quote exact text from the current key page, and confirm it; future practice uses that version and prior results retain the version they used. This path has synthetic feature coverage only and needs real scanned-paper/browser acceptance. Candidate-level written and fill-gap responses can receive qualitative, source-grounded step feedback with a separate source excerpt, but remain unscored; paper-set and mixed-paper results do not yet receive this feedback. Imported-question worked solutions remain open. Marks remain unknown when extraction is ambiguous. A live browser run on a supplied one-page Physics scan verified Mathpix extraction, 12 indexed MCQs, 11 practice-ready questions, formula rendering, and submitted results; the OCR-missing option in question 4 remained held for owner review. All 11 submitted responses were saved without a score because the paper has no verified answer key. That run predates the answer verification change and does not verify it. A mixed-paper live run is still needed. The concept-level practice generates original single-answer, four-option MCQs and one written response from concept-linked study chunks; latest-attempt points and the 70% review prompt are learning signals, not validated mastery.
