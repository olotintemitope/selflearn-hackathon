# Architecture
Laravel monolith with Blade/Livewire and queued provider calls. Use opaque UUIDs in learner-facing material URLs while retaining internal numeric keys for existing foreign-key compatibility. Reuse the existing extraction services described in docs/EXTRACTION_STACK.md; use private local filesystem storage for the recording POC; inspect reusable LearnKasts components before adapting them.

## Ingestion
Private upload → processing jobs (PDFs are extracted in resumable five-page batches by default, configurable up to ten pages per job) → material-aware extraction router (local text for readable ordinary PDF pages; Mathpix for unreadable pages, STEM cues, and meaningful raster/vector visuals) → page-linked chunks → local material relevance review → concept extraction from related pages → validated dependency graph → learning path. Relevance matching uses local topic terms first and puts weak matches into learner review. It must not require a paid model call. Persist the extraction version and next-page cursor after each batch so a retry can safely repeat the last batch. Show page progress to the learner; keep the original private and unchanged.
Use explicit pending/processing/ready/failed states, bounded retries, idempotent jobs, and visible retry controls. Retain originals and extraction versions. Flag uncertain OCR; do not silently correct original notes.

## Tutoring
Retrieve chunks scoped to the learner's learning space. Topic-launched tutoring carries the selected concept ID through the form and retrieval so the tutor receives that concept's linked source chunks, not merely keyword-overlapping pages. Pass source identifiers and assessed learner evidence. Return validated structured answers with real citations. If evidence is missing, state that and label any supplementary explanation.
For the POC, use a bounded chunk retrieval implementation; a vector database is optional. Never send an entire large library by default. If citation validation fails, only fall back to a selected concept's stored source-linked explanation and excerpts. An untargeted request may use a fallback only when its full concept name is explicit in the question and the retrieved chunks support it. Otherwise preserve the learner's question and ask them to choose or retry a topic instead of guessing.

## Adaptation
Grade MCQs on the server. Append evidence once per attempt. Unknown means unassessed, not 0% ability. Use the latest attempt for each concept as a transparent progress signal, combining server-graded MCQ points with AI-written points only when the written response is marked. Do not count pending, failed, or `needs_review` written responses as zeroes. Keep tutor check outcomes as a separate qualitative signal, never a numeric grade; a `needs_support` outcome recommends another explanation but does not lock navigation. Show attempted path coverage separately from the score. Use the 70% review prompt only as a recommendation, never as a mastery claim or navigation gate. After feedback, link directly to the suggested lesson, tutor, and practice action. Recommend a weak prerequisite only when it has related, ready source material in this learner's path. Validate graphs for cycles.

## Offline
Download a versioned text-first pack: path, source excerpts, generated explanations and quiz questions. Store locally in IndexedDB; service worker caches the app shell. Queue attempts with UUID idempotency keys. Grade and update authoritative evidence on reconnect. Label pending attempts; do not ship answer keys or API keys. Allow pack deletion and clear local user data on sign-out. Inspect the existing low-bandwidth implementation before building replacements.

Optional read-aloud is generated through OpenAI text-to-speech after the learner presses a control. Only that control's visible text is sent. Generated audio is cached privately per learner for up to 30 days so repeat listens do not incur another generation call. Online access is required for a cache miss; the readable source remains available as the fallback.

## Existing tools
Read docs/EXTRACTION_STACK.md. PDF extraction does not call OpenAI. The local page router uses text cues, embedded-image geometry, and rendered visual residuals to choose between `pdftotext -layout` and Mathpix. Full-page scans with readable text are compared for per-document visual outliers so a diagram page can be routed without sending every scanned prose page. This remains heuristic and needs representative corpus evaluation. AI providers are used after extraction for study guides, tutoring, practice, marking, relevance review, and translation. Tesseract is not the active OCR path. Reuse provider configuration. Bundle math renderer assets for offline study.
