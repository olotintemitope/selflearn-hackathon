# Workflow
1. Read the issue, AGENTS.md and relevant docs.
2. Inspect existing code and applicable instructions.
3. Identify the smallest change satisfying acceptance criteria.
4. Implement a complete vertical slice, including error states.
5. Test meaningful behavior and authorization; mock external providers.
6. Inspect the diff and verify each criterion with evidence.
7. Prepare a focused PR describing behavior, checks and limitations.
Use conventional commits. Report missing tools honestly; do not claim a PR was opened without a confirmed result.
